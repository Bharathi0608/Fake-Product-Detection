# 🛡️ FraudBlock – Blockchain-Based Fake Product Detection System

## 📌 Overview

FraudBlock is a blockchain-powered product verification system designed to combat counterfeit products in the supply chain. The platform enables manufacturers to register genuine products on the blockchain and allows consumers to verify product authenticity through a unique product ID.

By leveraging blockchain technology, FraudBlock ensures transparency, security, and tamper-proof product records, helping customers identify genuine products and reducing the circulation of counterfeit goods.

## 🏗️ System Architecture

1. Manufacturer registers a product.
2. Product details are stored on the blockchain.
3. A unique Product ID is generated.
4. Consumers enter or scan the Product ID.
5. Smart contracts verify the product record.
6. System displays Genuine or Fake status.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Bharathi0608/Fake-Product-Detection.git
cd Fake-Product-Detection
```

### Install Dependencies

```bash
npm install
```

### Start Ganache

Launch Ganache and create a local blockchain network.

### Compile Smart Contracts

```bash
truffle compile
```

### Deploy Contracts

```bash
truffle migrate --reset
```

### Run Backend Server

```bash
node server.js
```

### Start Frontend

```bash
npm start
```
